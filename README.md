## Deliverable
The final deliverable is a single runnable R Markdown (`.Rmd`) file. Open it in RStudio and knit it to run the analysis and generate the report.

## Insturctions to Run

To get RKaggle to pull dataset automatically:
1. Go to "Your API Tokens" on Kaggle.com and hit generate
2. Copy + put api-key generated on website into `~/.kaggle/kaggle.json`
3. Make sure RSession is restarted
4. Then run cell
